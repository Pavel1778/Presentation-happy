## 2026-10-07 (part 2) — happiness deck built end-to-end with ppt-master
- Project: `.agents/projects/happiness_concept_ppt169_20261007` (ppt-master resolves REPO_ROOT to `.agents/`, so projects live under `.agents/projects/`). Canvas ppt169 = 1280x720. 15 SVG pages authored from scratch.
- **Deliverables in `<proj>/exports/`**: `happiness_concept_20261007_211004_narrated.pptx` (15 slides, 15 embedded mp3, fade transitions, auto-advance by audio length, speaker notes), `happiness_concept_20261007.pdf` (1.3 MB), `preview/*.png` + `preview.html`.
- **Image embedding contract**: `<image href>` resolves relative to `svg_output/`, so the path is `../images/<file>.jpg` (NOT `images/...`). Full-bleed photo + the existing gradient rect with `fill-opacity="0.88"` = scrim (0.80 on the cover). Verify photos are actually visible by measuring the std-dev of a background patch (~60 = visible, <10 = washed out).
- **Attribution is a HARD gate**: every `attribution-required` (CC BY / CC BY-SA) image needs its OWN visible credit text. Format that passes: `© <author> / Wikimedia / CC BY-SA 4.0`. The checker matches the author string against `attribution_text` in `images/image_sources.json` — a truncated author (e.g. `Marek Ślusarczyk` vs `Marek Ślusarczyk ( Tupungato ) Photo portfolio`) FAILS. Use the exact string. `no-attribution` (CC0/PD) needs no credit.
- **edge-tts subtitle trap**: `notes_to_audio.py` aborts a page when a single TTS word-boundary exceeds the SRT char limit. The 28-char hyphenated token `Био-психо-социально-духовный` killed `05_science`. Fix = rewrite the note with short words. Keep hyphenated compounds short in RU notes.
- **Narrated export needs an explicit animation config**: `svg_to_pptx.py ... --recorded-narration audio` fails with "Animation config does not exist: narration_animations.json" unless you pass `--animation-config animations.json` or `--no-animations`. `--inherit-motion-from <base report.json>` alone is NOT enough.
- **Animation sidecar** `<proj>/animations.json`: `defaults.transition {effect:fade}`, `defaults.animation {effect:none}`, then per-slide `groups.<id>` rows `{effect:entrance_fade, order, duration, trigger:after-previous}`. Cover uses `"transition": {"effect":"none"}` (verified: slide1 gets only `advClick=0 advTm=...`, no visual effect). Validate with `animation_config.py validate`.
- **Font ratio rule**: title 36pt vs body must be <= 2x, so body >= 18pt. Generated SVGs had body at 22px (=16pt) -> ratio 2.25 (fail). Normalized body 22/26/28/30px -> 24px (=18pt), credits 18px -> 22px. Then `11_easterlin` overflowed horizontally (a 70-char line at 24px only fits ~1040px) -> split into 2 lines.
