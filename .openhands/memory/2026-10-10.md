## Slidev 53.0.0 gotchas (CLI installed GLOBALLY via sudo npm i -g)
- Vite cache defaults under /usr/local -> EACCES on export. Fix: `vite.config.ts` with
  `cacheDir: './.vite-cache'` as a **plain object** (no `import 'vite'`; vite is only global).
- Build failed in lightningcss minify ("Invalid token in pseudo element") -> set
  `build.cssMinify: false` in the same config.
- Export requires `playwright-chromium` installed locally in `presentation/` plus
  `npx playwright install chromium`.
- Images must use **absolute public paths** (`/screenshots/x.png`). A relative path makes
  Vite treat it as a module import; every slide then shows "Failed to resolve import"
  and the PDF exports with per-page error text.
- Export is RACY: `slidev export --per-slide --wait-until networkidle --wait 500` sometimes
  leaves slides blank on the first run. Retry until no page contains "error occurred".
  Script: `presentation/export_pdf.sh`.
- Theme background must be forced: set `html,body,#app,#slide-container,.slidev-page,
  .slidev-layout` background + `print-color-adjust: exact`, or the export comes out white.
