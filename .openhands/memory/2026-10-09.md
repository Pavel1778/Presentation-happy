## Phase 2 — review critique, commit 8a3c141 (pushed)
- **Environment reset wiped pip packages AND LibreOffice/poppler.** Reinstall:
  `pip install python-pptx lxml Pillow cairosvg pymupdf opencv-python-headless python-docx numpy requests PyYAML fonttools`
  and `apt-get install -y libreoffice-impress poppler-utils fonts-dejavu fonts-liberation`.
- **`LD_LIBRARY_PATH` is a trap.** The shell default
  `...:/usr/lib/aarch64-linux-gnu:/usr/lib:/usr/lib/x86_64-linux-gnu:` makes `soffice.bin`
  fail with `libreglo.so: cannot open shared object file` even though the file exists.
  Run python/cairosvg/soffice as `env -u LD_LIBRARY_PATH ...`.
- **`svg_quality_checker.py` typography-recurrence rule.** Any `font-size` not declared in
  `spec_lock.md` typography is an ERROR if it recurs >2× (e.g. a 15px credit). Fix: add a
  named role (`- credit: 15`). Also ERRORs: a `data-pptx-bounds` container that clips its own
  text, or two sibling root-module bounds that overlap (5% tolerance).
- **Cap clicks/slide**: PPTX `p:seq/p:cTn/p:childTnLst` top-level `p:par` count = click-groups.
  Merge by giving groups the SAME `order` + `trigger: with-previous` (+ small `delay`).
  Title stays `order 1` (auto). Verified 2–3 per slide.
- **Depression chart was mis-plotted** (curve began ~1%, not 8,2%). Sanity-check that a curve's
  start y matches its own data label.
- **"Centering" complaints were perceptual.** GIF + donut were already centred; they *read*
  off-centre because the title block was narrow. Fix = balanced titles + true compositing
  (donut cx=640, symmetric GIF padding). Measure centroids before moving anything.
- **Deliverables switched .txt→.docx** per critique: `Речь_доклада.docx` (956 words, ~8–9 min)
  and `Возможные_вопросы.docx` (12 Q&A, Q2 = dedicated 50/40/10 question). README updated.
- **Rebuild**: `svg_quality_checker.py --canonical-authoring --stage final` →
  `svg_to_pptx.py <proj> -f ppt169 --with-notes --animation-config animations.json
  --image-sizing display --image-quality 82 -o Konceptsiya_schastya.pptx` → `cp` to `_bez_video`
